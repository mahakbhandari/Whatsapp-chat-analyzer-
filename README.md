WhatsApp Chat Analyzer


📌 Problem Statement
WhatsApp chats contain a vast amount of personal and group conversation data, but extracting meaningful insights from them is difficult for most users. There is no straightforward way to quickly visualize chat statistics, patterns, and trends such as most active users, word frequency, or sentiment over time.

💡 Solution
The WhatsApp Chat Analyzer is a user-friendly web application that allows users to upload their exported WhatsApp chat files (in .txt format) and instantly generate comprehensive visualizations and insights from their chat data. This tool helps users understand their messaging habits, interaction patterns, and conversation dynamics with simple charts and statistics.


🚀 Features
Upload WhatsApp chat .txt file directly.

Analyze message counts over time (daily, monthly).

Identify most active participants in group chats.

Word cloud of most frequently used words.

Sentiment analysis on messages.

Visualize emojis usage and media sharing trends.

Download analysis reports.



🛠️ Technologies Used
Python for backend data processing.

Natural Language Processing (NLP) for text and sentiment analysis.

Streamlit for interactive web interface.

Pandas and Matplotlib/Seaborn for data visualization.



⚙️ How to Use
Export your WhatsApp chat from the app as a .txt file.

Open the WhatsApp Chat Analyzer web app.

Upload the exported .txt file.

View interactive charts and summaries generated automatically.
